# Avatars

The student avatars use the Micah style by Mike Mangialardi, licensed under CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/), generated with DiceBear (https://www.dicebear.com).

Each was generated with brown skin tones, dark hair and smiling expressions, then exported as
a 256px PNG with a transparent background. No changes were made to the artwork itself.
